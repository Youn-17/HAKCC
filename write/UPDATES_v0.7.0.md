# v0.7.0：讨论分析

知识空间新增独立分析页：词云、关键词变化、观点接力和待推进议题。支持全体或单个学生、视图与日期筛选；点击结果可查看来源 Note 并回到画布。词云设置、匿名展示和 PNG 导出保留在页面内。

分析来自学生写的 Note 与已采纳的 Build-on。关键词变化按 Note 创建时间划分当前正文，不能替代历史修订对照。词频不代表掌握程度，待推进议题需教师读原文确认。协作文档正文暂未纳入。

同时收录可选的课程资料引用核对与草稿支架建议。配置和密钥由部署者自行提供。

前端：Node 22，npm ci，npm run build。API：在 api/ 内 npm ci 和 npm run build。文本工具需 Python、jieba、wordcloud 和支持中文的字体；缺少 Python 时，观点接力与待推进议题仍可使用。无新增数据库迁移。

验证范围与限制见 [发布检查](../evidence/RELEASE_VALIDATION.md)。该公开包不包含生产配置、真实学生数据或内部部署文档。
