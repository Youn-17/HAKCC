# v0.6.0：协作文档与情境绘图

[首页](../README.zh-CN.md) · [English](UPDATES_v0.6.0.en.md) · [验证记录](../evidence/RELEASE_VALIDATION.md)

知识空间成员可创建协作文档卡片，双击进入多人同步编辑。界面提供开始、插入、视图工具栏，纸张视图、标尺、样式、字数和缩放；支持段落、标题、常见文字格式、列表、表格和 PNG/JPG 图片。编辑器按钮目前使用中文标签。

## 权限、保存与数据归属

卡片仍是 Supabase 中的 Note，正文和快照由独立 SQLite 服务保存，房间 ID 与 Note ID 相同。API 检查课程成员、小组归属和删除状态；实验模式下，共享空间普通参与者只读，课程工作人员沿用既有权限。连接每 30 秒重新校验，结合现有缓存，撤权可能延迟约 90 秒。普通 Note 更新不能伪造或移除协作标记。

SQLite 使用 WAL 和 FULL 同步。客户端的规范化完整 Yjs 状态匹配服务端落盘确认后才显示“已保存”；离线修改按账号和文档隔离在浏览器 IndexedDB，只读会话不上传旧的待同步修改。正文初始化失败时，API 补偿清理新建卡片。

每篇文档保留最近 20 个快照，可手动“保存版本”，也可在间隔五分钟后的新修改时自动保存。暂不提供快照恢复界面。这与服务器应用版本的保留数量是两件事。

## 本地体验

安装 Docker 并启动，准备 Node.js 22.22.3，在仓库根目录运行：

```bash
bash scripts/start_collab_demo.sh
```

访问 http://localhost:3110 ，分别使用虚构学生 A、B 和只读访客。无需真实课程或 Supabase 项目。端口只绑定本机，脚本生成私有本地配置；重建容器和普通停止会保留数据卷，删除卷会删除正文。

不要将 demo 原样公开到公网。生产模式明确禁止虚构身份登录。本地示例数据不会自动同步到远程服务器。

## 接入自己的平台

前端构建设置 `VITE_ENABLE_COLLAB_DOCUMENTS=true`。API 设置 `COLLAB_ENABLED=true`、`COLLAB_INTERNAL_URL`、`COLLAB_PUBLIC_WS_URL` 和 `COLLAB_SECRET`。协作服务设置生产模式、关闭 demo，配置 `COLLAB_AUTH_API_URL`、精确的 `COLLAB_ORIGINS` 和独立数据目录。

内部共享密钥至少 32 字符，不能放入前端。浏览器使用现有账号令牌，协作服务调用 API 检查房间权限。公网代理只开放 TLS WebSocket 路径，内部文档 HTTP 接口保持私有。

[生产 Compose 模板](../docker/docker-compose.collab-production.yml) 用于 Linux，要求自行提供镜像名称、私有环境文件、数据目录和既有 API 地址。容器默认限制 512 MiB 内存和 1 CPU，不代表已确认的并发容量；正文目录需允许容器 UID 1000 写入。正文独立于应用 release 保存，使用 SQLite 在线备份并验证完整性，不能只复制运行中的主库而遗漏 WAL。异地备份需由部署者配置。

本次没有新增 Supabase 迁移，但依赖现有 Note metadata、视图、课程和成员结构。历史迁移全量重放和全新数据库安装仍未验收。

## 其他更新与边界

近期源码增加情境绘图、修改上一张图、结构图绘制及可选 Jev 路由和规划检查，并改进画布搜索、Build-on 折叠、语言偏好、课程设置和人员导出。Node 运行要求统一到 22.22.3，保留此前公开版的依赖修补。

新协作文档的独立正文尚未接入 AI、课程知识库和研究导出，不能把空的 Note.content 当作正文。单篇状态最多 8 MiB，单图 1 MiB；Word 导出保留基本格式，复杂排版可能不同。纸张视图不是完整分页引擎，暂不支持 Word 导入、批注、修订和快照恢复。

公开包只提供脱敏源码和说明，不包含真实课程、学生记录、密钥、服务器资料或私有研究。软件功能与设计意图不等于学习效果；既有记忆功能属于应用保存和检索，不是训练模型权重。
