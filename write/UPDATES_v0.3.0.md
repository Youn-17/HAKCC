## 新增与改进

| 功能 | 使用方式与作用 |
| --- | --- |
| 知识地图 | 从 Build-on 网络查看分支与时间布局，按作者、日期、关系类型和分支筛选，追踪某条观点的前后联系，定位原 Note；布局依据已有关系，不是 AI 对观点质量的评分 |
| 构建时间线 | 查看整体、Note 与成员轨迹，按空间、小组、成员、日期、事件类型筛选，查看修订摘要；构建序列按实际时间回放，保留活动间隔 |
| 反馈采纳 | 采纳后先修订原 Note，贡献时检查是否回应反馈；回应充分时保留原 Note，未回应的采纳项才可能生成关联反馈 Note |
| AI 过程显示 | 显示工具名称、状态、结果摘要和用时；完成后折叠为可展开的过程摘要，不展示模型原始思考内容 |
| 回答长度与阅读设置 | 简短、适中、详细三档，结合问题深浅调整；本机保存 Enter 发送、较大对话文字等偏好 |
| View 讨论主题 | 滚动显示有来源 Note 的讨论主题，按笔记变化与缓存刷新；用于定位讨论，不代替学生综合结论 |
| 可选 Jev 判断 | 服务端配置 off、shadow、gate 模式；没有密钥时关闭；判断失败有原有模型路径或启发式回退 |
| 反馈检查记录 | 记录进入判断阶段后的触发、静默等结果，支持有权限的过程导出；前置门槛未通过的尝试不记为模型判断 |
| 课程成员与帮助 | 区分教师和学生人数；学生求助沿课程路径处理，教师无法解决的技术求助转平台管理员 |

机制图、KF 参考文献、可编辑 draw.io 与虚构演示素材继续保留。既有图和动图说明基础机制，未覆盖所有本次新增界面；当前主题生成提示词等部分内容仍以中文课程为主。

## 学生操作与反馈回应

进入有权限的课程空间，在 Build-on 网络中选中观点、追踪联系，查看原 Note 或构建时间线。时间线支持不同轨迹和筛选条件；回放只改变呈现时钟，不更改记录或导出范围。

接受 AI 反馈不会立刻产生公共反馈 Note。先改进原 Note，再点击贡献：系统核验作者、课程权限、原始快照与当前修订。提取学生正文时排除 AI 摘录和支架标签；仅修改文字并不等于回应了建议，回应检查还需要来自新增正文、未直接复制反馈的证据片段。

已回应的建议由改进后的原 Note 承载。未回应的采纳项可按权限生成关联 Note；证据不足、模型失败或修订发生并发变化时，结果可能保持待判断，稍后重试。关闭编辑器本身不完成回应检查。自动判断可能出错，学生仍需检查内容与来源。

回答长度是提示目标，不是严格字数限制。执行过程显示帮助查看工具实际完成了什么，不能保证工具或 AI 给出的结论正确。

## 教师配置、权限与导出

教师需要配置课程 AI 服务、反馈类别、灵敏度和主题开关。主题生成还受笔记数量、适用条件和缓存状态约束，失败时可能显示已有主题或暂不显示。

课程范围时间线只读取请求者有权访问的空间；私人 AI 反馈和 Note 对话只读取请求者自己的记录。教师身份不会获得他人的私人 AI 活动。小组归属基于当前名单，不代表历史名单。

时间线的 CSV 与 JSON 清单导出仅供课程工作人员使用，保留事件时间、稳定参与者代号、筛选条件、覆盖范围和成员背景，不导出 Note 标题及正文。事件、Note、课程、空间、小组标识仍在，因此这是受权限约束的过程数据，不保证无法重新识别。其他研究导出具有各自字段与权限。

覆盖信息标注截断和修订快照不完整；历史表缺少编辑时间列时可能使用创建时间。缺失记录无法通过回放恢复。活动计数与网络不直接衡量知识质量或教学效果。

## 升级要求

[安装指南](../GETTING_STARTED.md)说明基础配置。已有安装需先检查实际数据库版本与备份，在隔离环境依次验证：

1. [074](../supabase/migrations/074_feedback_suggested_title.sql)：反馈建议标题。
2. [075](../supabase/migrations/075_support_asker_role.sql)：师生求助角色。
3. [076](../supabase/migrations/076_view_topic_summaries.sql)：服务端主题缓存。
4. [077](../supabase/migrations/077_feedback_trigger_checks.sql)：服务端反馈检查记录。

本次发布没有运行生产数据库迁移或部署线上站点。历史迁移仍有重复编号和修复脚本，尚未验证从空数据库完整重放。

可选 Jev 配置见 [api/.env.example](../api/.env.example) 和英文说明。密钥仅存服务端：空密钥时关闭；shadow 只并行记录，主模型决定反馈；gate 由 Jev 判断是否需要及类别，主模型生成正文，失败回退。off 仅关闭反馈判断，回答深浅需另设 `JEV_ANSWER_LENGTH=off`。阈值是可配置默认值，不是已验证的教学标准。

启用外部判断会发送有长度上限的 Note 标题、正文或问题片段；不追加个人资料姓名，但正文可能含用户自行写入的身份信息。课程管理者需按适用的数据使用安排决定是否启用。
