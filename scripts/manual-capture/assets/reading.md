# 检索练习：为什么「回想」比「重读」记得牢

本周阅读材料的导读。原文：Roediger, H. L., & Karpicke, J. D. (2006). Test-enhanced learning: Taking memory tests improves long-term retention. *Psychological Science, 17*(3), 249–255.

## 一、研究在比较什么

学生先读一篇短文，然后分成两组：一组把短文再读一遍，另一组合上材料，把记得的内容写下来。之后隔不同的时间做同一份测验，看谁记得多。

## 二、主要发现

- 隔几分钟就测，重读的一组略好一些。
- 隔两天、隔一周再测，结果反过来：做过回想的一组记得明显更多。
- 第二个实验里，只读不测的学生对自己的记忆最有信心，一周后的成绩却最差。

## 三、和我们讨论的关系

画布上有同学说「用 AI 查资料以后，记住的反而更少」。直接读 AI 给的总结，很像实验里的「重读」：当下觉得都懂了，过几天就想不起来。

## 四、需要注意的地方

这项研究比较的是回想和重读，没有研究 AI。拿它支持「AI 会让人变懒」之前，要先说清楚：你观察到的现象和实验条件哪里一样、哪里不一样。
